# dykkos.github.io

Personal website: https://dykkos.github.io/

A plain HTML academic index inspired by the subject-grouped layout of Ben Green's publications page. Serif text, a pale paper background, linked lists, and minimal CSS. No build step.

- `index.html`: Academic and Project sections.
- `math.html`: subject index; existing PDF URLs retained; MAT1307 notes remain in progress.
- `cs.html`: project index and WikiClick validation curve.
- `systems.html`: Kali Linux and Wireshark lab summaries and external references.
- `p2p.html`: WireGuard and Tailscale experiments.
- `ai-safety.html`, `blog.html`, `intro.html`, `misc.html`: existing pages retained.

Preview with `python3 -m http.server 8000`.

`images/wikiclick-learning-curve.png` is copied unchanged from
`bowen-pixel/WikiClick/figures/learning_curves/LC03_next_link_validation_1000.png`.
It shows offline validation histories on a saved 1,000-article graph, not live-web results.
The full-resolution image and original figure catalogue are linked from the project entry.
